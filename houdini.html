Installation and health checks

A Houdini upgrade changes the Houdini version, the Python version, and the preference folder together. Each change can stop a tool with no error message. Three commands solve this. One checks that Houdini's Qt libraries load. One installs every package for every Houdini version on the machine. One reports PASS or FAIL for the whole toolset.
