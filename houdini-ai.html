AI inside Houdini

Two separate channels: one lets Claude act on a live Houdini session, and one lets you talk to Claude in a Houdini panel.

 Live scene
  • Tools. Ten tools read the scene, create and delete nodes, read and set parameters, return cook errors and geometry statistics, run Python, and return a VEX reference sheet.
  • Threading. Every call runs on the Houdini main thread, because the API is not safe from a socket thread.
  • Start. A Houdini package starts the bridge when the interface opens. The same bridge also runs headless.
  • Access. The listener accepts local connections only. It runs any Python that it receives, by design, so it is for a trusted local session.

 Watcher process > Claude CLI > bridge > scene

   v
 Panel in Houdini
  • Transport. Two append-only files carry the messages, and each file has one writer. Either side can restart with no loss.
  • Interface. The panel never waits on another process, so a slow reply cannot freeze Houdini. It shows if the watcher runs, and it can start it.
  • Scene access. The panel can use the bridge, so Claude can act on the scene as well as discuss it.

How it was verified

A test object with 77 points existed only in the live scene. A question typed in the real panel returned 77 through the real chain, with nothing simulated. A repeat on Houdini 22 returned 65 points from a new test object in 12 s.

The tests found real defects:

  • Houdini runs package start-up code with no file path variable. Autostart failed with no visible error until a test copied that condition.
  • Non-ASCII text was corrupted because one direction of each pipe used the Windows code page. Both directions now use UTF-8.
  • The panel imported a Qt version that Houdini no longer ships.

Limits

  • A bridge call stops waiting after 180 s, but the work continues in Houdini. Sending the call again starts a second render.
  • Windows application control can block Houdini's Python and stop the watcher button. A manual start works.
  • The code that reports the selected node has not run in a live panel.
